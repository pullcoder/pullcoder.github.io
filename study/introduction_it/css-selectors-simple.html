CSS 선택자 6가지 완벽 정리

HTML 요소를 정확하게 지목하는 CSS 선택자의 핵심 유형과 코드 예제

01 * 전체 선택자

문서 안의 모든 요소를 동시에 선택합니다. 브라우저 기본 스타일을 초기화하는 CSS Reset에 주로 사용됩니다.

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box; /* 모든 요소에 적용 */
}
02 .class 클래스 선택자

점(.) 뒤에 클래스 이름을 붙여, 해당 class 속성을 가진 모든 요소를 선택합니다. 재사용이 가능해 실무에서 가장 많이 사용됩니다.

.highlight {
  background: yellow;
  font-weight: bold; /* class="highlight"인 요소 전체 */
}
03 #id ID 선택자

샵(#) 뒤에 ID를 붙여 고유한 단 하나의 요소를 선택합니다. 특이성(Specificity)이 높아 다른 스타일을 쉽게 덮어씁니다.

#main-title {
  font-size: 32px;
  color: #2563eb; /* id="main-title"인 요소 1개만 */
}

04 A  B 자손 선택자

두 선택자 사이에 공백을 두어, 왼쪽 요소의 하위(자식·손자 포함) 요소 중 오른쪽 조건을 만족하는 요소를 선택합니다.

.card span {
  color: hotpink; /* .card 안의 모든 span */
}
.card > p {
  margin: 0; /* 직계 자식 p만 (> 사용) */
}
05 [attr] 속성 선택자

대괄호 [] 안에 조건을 넣어 특정 속성이나 속성값을 가진 요소를 선택합니다. 시작(^=), 끝($=), 포함(*=) 패턴을 지원합니다.

a[href^="https"] { color: green; } /* https로 시작 */
a[href$=".pdf"]  { color: red; }   /* .pdf로 끝남 */
input[type="text"] { border: 2px solid blue; }
06 :pseudo 가상 클래스

콜론(:)으로 시작하며 요소의 특정 상태나 위치를 기반으로 선택합니다. 마우스 오버·첫 번째 자식·홀짝수 행 등 다양한 조건에 사용합니다.

a:hover              { color: red; }    /* 마우스 오버 */
li:first-child       { font-weight: bold; } /* 첫 번째 */
tr:nth-child(even)   { background: #f5f5f5; }

선택자 한눈에 비교

선택자 종류 선택 대상 특이성
* 전체 문서 내 모든 요소 0, 0, 0
.class 클래스 해당 클래스를 가진 모든 요소 0, 1, 0
#id ID 해당 ID를 가진 고유 요소 1개 1, 0, 0
A B 자손 A 하위의 모든 B 요소 조합에 따라 상이
[attr] 속성 특정 속성 또는 값을 가진 요소 0, 1, 0
:pseudo 가상 클래스 특정 상태·위치의 요소 0, 1, 0
💡 특이성(Specificity) 우선순위:   인라인 스타일 > ID 선택자 > 클래스·속성·가상 클래스 > 태그 선택자 > 전체 선택자
