## SWOT 매트릭스 전략 (2차안)

### 1. SO 전략 (강점-기회: 강점으로 기회를 포착)

- **신뢰 중심 AI 비서 입지 구축:** 목표 승인, 결제 직전 정지, 승인 전 화면 미전송이라는 안전 설계를 앞세워, 사용자가 결정권을 가진 채로 주문·예약 과정을 도움받는 "사용자 주도형 AI 비서" 입지 구축
- **단계적 확장:** 1단계로 대화와 음성 기능으로 기본 UX를 확보한 뒤, 배달 → 지도 → 기차 순서로 허락받은 앱만 지원 범위를 넓혀 공식 API가 없는 영역 확장

### 2. WO 전략 (약점-기회: 기회를 활용해 약점 극복)

- **앱별 레시피 구조:** 대상 앱 UI 변경 시 전체가 멈추는 약점을 줄이기 위해, 앱별 실행 순서를 독립 레시피로 분리해 빠르게 수정하는 체계 마련
- **테스트 단계 사전 검증:** 정식 출시 전 테스트 배포로 실제 사용자 불편사항과 오류 패턴을 모으고 완성도 향상

### 3. ST 전략 (강점-위협: 강점으로 위협을 회피)

- **여러 겹의 안전장치로 오결제 위험 최소화:** 예기치 못한 팝업이나 오작동에 대비해 20단계 제한, 동작 간 100ms 간격, 결제 직전·추가 질문·앱 이탈·사용자 터치 시 그 자리에서 멈추고 사용자에게 넘김
- **정밀 필터링으로 보안 이슈 사전 차단:** 화면 구조를 읽을 때 로그인·비밀번호·금융 화면은 보내지 않고, 금융·메신저 앱은 실행을 거부해 스토어 심사와 보안 문제 발생 여지 축소

### 4. WT 전략 (약점-위협: 약점과 위협을 최소화)

- **딥링크(Deep Link) 우선 적용 정책:** AccessibilityService에만 의존하지 않고, 지도 앱처럼 가능한 구간은 공식 딥링크를 우선 활용해 UI 변경에 따른 파손 위험과 유지보수 부담 축소
- **OS 접근성 자동 종료 대응:** 백그라운드 서비스 강제 종료에 대비해 서비스 상태를 감지하고, 권한 해제 시 사용자에게 재활성화 안내 제공
