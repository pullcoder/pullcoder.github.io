1객체란 무엇인가

객체(Object)는 서로 관련된 데이터와 기능을 하나로 묶은 상자입니다. 상자 안에는 이름표(키): 값 쌍이 들어 있습니다.

예를 들어 "학생 한 명"을 표현하려면 이름, 나이, 학년을 각각 따로 변수로 만드는 것보다 하나의 객체로 묶는 편이 훨씬 관리하기 쉽습니다.

name"김철수"
age20
grade2
study()공부하는 기능
/* ===== 실행 순서 =====
 * ① 변수 3개로 학생 정보를 따로 저장
 * ② 객체 1개로 학생 정보를 묶어서 저장
 * ③ 두 방식을 출력해서 비교
 * ====================== */

// ① 따로따로 저장 → 학생이 늘어나면 변수가 폭발적으로 많아짐
let studentName = "김철수";
let studentAge = 20;
let studentGrade = 2;

// ② 객체로 묶어서 저장 → { 키: 값, 키: 값 } 형태
const student = {
  name: "김철수",   // 키 name, 값 "김철수"
  age: 20,          // 키 age, 값 20
  grade: 2          // 키 grade, 값 2
};

// ③ 출력
console.log(studentName, studentAge, studentGrade);
console.log(student);       // 객체 전체 출력
console.log(typeof student); // 자료형 확인 → "object"
💡 한 줄 정리객체 = 이름(키)으로 값을 찾는 데이터 묶음. 중괄호 { }로 만듭니다.

2속성(Property)과 메서드(Method)

객체 안의 구성 요소는 두 종류로 나뉩니다.

구분의미비유예시
속성 (Property)객체가 가진 데이터(값)명사 · 특징name: "초코"
메서드 (Method)객체 안에 들어 있는 함수(기능)동사 · 행동bark() { ... }
 
/* ===== 실행 순서 =====
 * ① dog 객체 생성 (속성 3개 + 메서드 2개)
 * ② 속성 값 출력
 * ③ 메서드 호출 → 함수가 실행되어 결과 반환
 * ====================== */

// ① 객체 생성
const dog = {
  // --- 속성(데이터) ---
  name: "초코",
  breed: "푸들",
  age: 3,

  // --- 메서드(기능) : 방법 1 - function 키워드 ---
  bark: function () {
    return "멍멍!";
  },

  // --- 메서드(기능) : 방법 2 - 단축 문법 (ES6, 더 많이 씀) ---
  eat(food) {
    return food + "를 맛있게 먹어요";
  }
};

// ② 속성 출력
console.log("이름:", dog.name);
console.log("견종:", dog.breed);

// ③ 메서드 호출 → 반드시 괄호 () 를 붙여야 실행됨
console.log(dog.bark());
console.log(dog.eat("사료"));

// 괄호 없이 쓰면 실행되지 않고 '함수 자체'를 가리킴
console.log(typeof dog.bark); // "function"
⚠️ 자주 하는 실수dog.bark 와 dog.bark()는 다릅니다. 괄호가 있어야 메서드가 실행됩니다.

3객체 생성 방법

객체를 만드는 방법은 여러 가지가 있지만, 초보자는 ① 객체 리터럴부터 익히면 충분합니다. 같은 모양의 객체를 여러 개 만들 때 ③, ④를 사용합니다.

방법문법언제 쓰나
① 객체 리터럴{ 키: 값 }가장 기본. 객체 1개를 빠르게 만들 때
② new Object()new Object()빈 객체를 만든 뒤 속성을 추가 (거의 안 씀)
③ 생성자 함수function Car() {} + new같은 구조의 객체를 여러 개 찍어낼 때
④ 클래스class Car {} + new③의 최신 문법. Java의 클래스와 비슷
 
/* ===== 실행 순서 =====
 * ① 객체 리터럴로 생성
 * ② new Object()로 빈 객체 생성 후 속성 추가
 * ③ 생성자 함수 정의 → new로 객체 2개 생성
 * ④ 클래스 정의 → new로 객체 생성
 * ====================== */

// ① 객체 리터럴 (가장 많이 사용)
const car1 = { brand: "현대", model: "아반떼" };
console.log("① 리터럴:", car1);

// ② new Object()
const car2 = new Object();   // 빈 객체 {}
car2.brand = "기아";         // 나중에 속성 추가
car2.model = "K5";
console.log("② new Object:", car2);

// ③ 생성자 함수 (이름은 대문자로 시작하는 것이 관례)
function Car(brand, model) {
  this.brand = brand;   // this = 새로 만들어질 객체
  this.model = model;
}
const car3 = new Car("제네시스", "G80");
const car4 = new Car("쉐보레", "트랙스");
console.log("③ 생성자:", car3, car4);

// ④ 클래스 (ES6)
class Phone {
  constructor(maker, price) {   // new 할 때 자동 실행
    this.maker = maker;
    this.price = price;
  }
  info() {                      // 메서드
    return this.maker + " / " + this.price + "원";
  }
}
const phone = new Phone("삼성", 1200000);
console.log("④ 클래스:", phone.info());

4속성 접근 — 점 표기법과 대괄호 표기법

표기법형태특징
점 표기법obj.key짧고 읽기 쉬움. 대부분 이 방법 사용
대괄호 표기법obj["key"]키가 변수에 들어 있거나, 공백·하이픈이 있는 키일 때 필수
 
/* ===== 실행 순서 =====
 * ① book 객체 생성
 * ② 점 표기법으로 접근
 * ③ 대괄호 표기법으로 접근 (문자열 키 / 변수 키 / 공백 있는 키)
 * ④ 없는 속성 접근 → undefined
 * ⑤ in 연산자로 속성 존재 여부 확인
 * ====================== */

// ① 객체 생성 ("출판 연도"처럼 공백 있는 키는 따옴표 필수)
const book = {
  title: "자바스크립트 첫걸음",
  price: 18000,
  "출판 연도": 2026
};

// ② 점 표기법
console.log(book.title);

// ③ 대괄호 표기법
console.log(book["price"]);       // 키를 문자열로
const key = "title";              // 키가 변수에 들어 있을 때
console.log(book[key]);           // book.key 로 쓰면 안 됨!
console.log(book["출판 연도"]);    // 공백이 있는 키

// ④ 존재하지 않는 속성 → 에러가 아니라 undefined
console.log(book.author);

// ⑤ 속성이 있는지 확인
console.log("title" in book);   // true
console.log("author" in book);  // false
🔎 왜 book.key는 안 될까?book.key는 변수 key의 값이 아니라 이름이 "key"인 속성을 찾습니다. 변수에 담긴 키를 쓰려면 반드시 book[key]를 사용하세요.

5속성 추가 · 수정 · 삭제

객체는 만든 후에도 자유롭게 속성을 바꿀 수 있습니다. 문법은 아주 단순합니다.

작업문법설명
추가obj.새키 = 값없는 키에 값을 넣으면 새로 생김
수정obj.기존키 = 새값있는 키에 값을 넣으면 덮어씀
삭제delete obj.키속성 자체를 제거
 
/* ===== 실행 순서 =====
 * ① user 객체 생성
 * ② 속성 추가 (email, 메서드 hello)
 * ③ 속성 수정 (age 값 변경)
 * ④ 속성 삭제 (email 제거)
 * ⑤ 각 단계마다 객체 상태 출력
 * ====================== */

// ① 생성
const user = { name: "이영희", age: 22 };
console.log("① 처음:", user);

// ② 추가 : 없는 키에 값을 대입
user.email = "young@example.com";
user["city"] = "성남";              // 대괄호로도 추가 가능
user.hello = function () {          // 메서드도 나중에 추가 가능
  return "안녕하세요!";
};
console.log("② 추가 후:", user);
console.log(user.hello());

// ③ 수정 : 있는 키에 새 값 대입
user.age = 23;
console.log("③ 수정 후 age:", user.age);

// ④ 삭제 : delete 연산자
delete user.email;
console.log("④ 삭제 후:", user);
console.log("email 남아 있나?", "email" in user);
💡 const인데 왜 바뀌나요?const는 변수가 다른 객체를 가리키지 못하게 막을 뿐, 객체 내부의 속성 변경은 막지 않습니다. 즉 user.age = 23은 OK, user = {}는 에러입니다.

6this 키워드

메서드 안에서 this는 그 메서드를 호출한 객체 자신을 가리킵니다. "나 자신의 속성"을 사용할 때 씁니다.

/* ===== 실행 순서 =====
 * ① counter 객체 생성 (count 속성 + 메서드 3개)
 * ② increase() 3번 호출 → this.count 증가
 * ③ show() 호출 → this.count 출력
 * ④ reset() 호출 후 다시 출력
 * ====================== */

// ① 객체 생성
const counter = {
  count: 0,
  increase() {
    this.count = this.count + 1;  // this = counter 객체
  },
  reset() {
    this.count = 0;
  },
  show() {
    return "현재 숫자: " + this.count;
  }
};

// ② 증가
counter.increase();
counter.increase();
counter.increase();

// ③ 출력
console.log(counter.show());   // 현재 숫자: 3

// ④ 초기화 후 출력
counter.reset();
console.log(counter.show());   // 현재 숫자: 0
/* ===== 실행 순서 =====
 * ① 공통 함수 introduce 정의 (this 사용)
 * ② 두 객체에 같은 함수를 메서드로 연결
 * ③ 각각 호출 → this가 호출한 객체로 바뀜
 * ====================== */

// ① this를 사용하는 함수
function introduce() {
  return "안녕, 나는 " + this.name + "이야!";
}

// ② 두 객체가 같은 함수를 공유
const kim = { name: "김민수", introduce: introduce };
const park = { name: "박지은", introduce: introduce };

// ③ 점(.) 앞의 객체가 this가 된다
console.log(kim.introduce());   // this = kim
console.log(park.introduce());  // this = park
/* ===== 실행 순서 =====
 * ① 일반 메서드와 화살표 함수 메서드를 가진 객체 생성
 * ② 각각 this가 객체 자신인지 확인
 * ====================== */

// ① 객체 생성
const obj = {
  name: "테스트",
  normal: function () {
    return this === obj;   // 일반 함수 → this는 obj
  },
  arrow: () => {
    return this === obj;   // 화살표 함수 → 자기 this가 없음!
  }
};

// ② 비교
console.log("일반 함수 this === obj :", obj.normal()); // true
console.log("화살표 함수 this === obj :", obj.arrow()); // false
⚠️ 규칙객체의 메서드에서 this를 쓸 거라면 화살표 함수(=>)를 쓰지 마세요. 일반 함수 또는 단축 문법 method() { }을 사용합니다.

7중첩 객체

객체의 값으로 또 다른 객체나 배열을 넣을 수 있습니다. 점을 이어서 안쪽으로 들어갑니다.

/* ===== 실행 순서 =====
 * ① 주소(객체)와 취미(배열)를 품은 member 객체 생성
 * ② 점을 이어 붙여 안쪽 값 접근
 * ③ 중첩된 값 수정 및 추가
 * ④ 옵셔널 체이닝(?.)으로 안전하게 접근
 * ====================== */

// ① 중첩 객체 생성
const member = {
  name: "정하늘",
  address: {                 // 객체 안의 객체
    city: "서울",
    zip: "04524",
    detail: {                // 더 깊은 객체
      building: "하늘빌딩",
      floor: 7
    }
  },
  hobbies: ["게임", "코딩"]  // 객체 안의 배열
};

// ② 접근 : 바깥 → 안쪽 순서로 점 연결
console.log(member.address.city);             // 서울
console.log(member.address.detail.floor);     // 7
console.log(member["address"]["zip"]);        // 대괄호도 가능
console.log(member.hobbies[1]);               // 배열은 인덱스로

// ③ 수정과 추가
member.address.city = "성남";
member.address.detail.room = 701;
member.hobbies.push("독서");
console.log(member.address);
console.log(member.hobbies);

// ④ 없는 중간 단계 접근
// console.log(member.company.name);  // 에러! company가 undefined
console.log(member.company?.name);     // ?. 를 쓰면 에러 대신 undefined
🔎 옵셔널 체이닝 ?.앞의 값이 undefined나 null이면 더 들어가지 않고 undefined를 돌려줍니다. 서버에서 받은 데이터처럼 구조가 확실하지 않을 때 유용합니다.

8for...in 반복문

for (const 키 in 객체)는 객체의 모든 키를 하나씩 꺼내며 반복합니다. 키가 변수에 담기므로 값은 대괄호 표기법으로 꺼냅니다.

/* ===== 실행 순서 =====
 * ① scores 객체 생성
 * ② for...in으로 키를 하나씩 꺼내 출력
 * ③ 반복하며 총점 누적 → 평균 계산
 * ====================== */

// ① 과목별 점수
const scores = { 국어: 90, 영어: 85, 수학: 100, 과학: 75 };

// ② 키 순회 : subject에 "국어", "영어", ... 가 차례로 들어감
for (const subject in scores) {
  console.log(subject + " → " + scores[subject] + "점");
  // scores.subject 는 X  (이름이 "subject"인 속성을 찾음)
}

// ③ 합계와 평균
let total = 0;
let count = 0;
for (const subject in scores) {
  total += scores[subject];
  count++;
}
console.log("총점:", total, "/ 평균:", total / count);

보너스: Object.keys / values / entries

키·값을 배열로 받아서 처리하고 싶을 때 사용합니다. 실무에서는 이 방식도 많이 씁니다.

/* ===== 실행 순서 =====
 * ① 객체 생성
 * ② 키 배열 / 값 배열 / [키, 값] 쌍 배열 출력
 * ③ entries를 for...of로 순회
 * ====================== */

// ① 객체
const fruit = { 사과: 3, 바나나: 5, 포도: 2 };

// ② 배열로 변환
console.log(Object.keys(fruit));     // ["사과","바나나","포도"]
console.log(Object.values(fruit));   // [3,5,2]
console.log(Object.entries(fruit));  // [["사과",3], ...]

// ③ [키, 값]을 구조 분해로 받아 순회
for (const [name, qty] of Object.entries(fruit)) {
  console.log(name + "는 " + qty + "개");
}

개수 확인Object.keys(obj).lengtharr.length
추가obj.새키 = 값arr.push(값)

권장 반복문for...in, Object.entries()for...of, forEach()

/* ===== 실행 순서 =====
 * ① 배열 하나 / 객체 하나 비교
 * ② 객체들을 배열에 담은 '객체 배열' 생성
 * ③ for...of로 배열 순회, 각 객체의 속성 출력
 * ④ 배열과 객체 구분하기
 * ====================== */

// ① 비교
const colors = ["빨강", "초록", "파랑"];        // 같은 종류 여러 개 → 배열
const product = { name: "키보드", price: 50000 }; // 하나의 대상 설명 → 객체
console.log(colors[0], "/", product.name);

// ② 실무에서 가장 흔한 형태 : 객체 배열
const products = [
  { name: "키보드", price: 50000 },
  { name: "마우스", price: 30000 },
  { name: "모니터", price: 250000 }
];

// ③ 배열은 for...of, 각 요소(객체)는 점 표기법
for (const item of products) {
  console.log(item.name + " : " + item.price.toLocaleString() + "원");
}

// ④ typeof는 둘 다 object → Array.isArray로 구분
console.log(typeof colors, typeof product);
console.log(Array.isArray(colors), Array.isArray(product));

10핵심 요약

📦 객체

{ 키: 값 } 쌍의 묶음. 관련된 데이터를 하나로 관리

🏷️ 속성 / ⚙️ 메서드

속성 = 데이터, 메서드 = 객체 안의 함수. 메서드는 ()로 호출

🏗️ 생성

기본은 리터럴 {}. 여러 개 찍어낼 땐 생성자 함수 / class + new

🔑 접근

obj.key 또는 obj["key"]. 변수 키는 대괄호만 가능

✏️ 추가·수정·삭제

대입하면 추가/수정, delete obj.key로 삭제

👆 this

메서드를 호출한 객체 자신. 메서드에 화살표 함수 사용 금지

🪆 중첩 객체

a.b.c로 안쪽 접근. 불확실하면 ?.

🔁 for...in

키를 하나씩 꺼냄 → 값은 obj[key]

⚖️ 객체 vs 배열

이름으로 찾으면 객체, 순서·번호로 찾으면 배열

11복습 문제

먼저 스스로 답을 생각해 본 뒤 정답 보기를 눌러 확인하세요.

Q1. 다음 코드의 출력 결과는?
const pet = { name: "나비", type: "고양이" };
console.log(pet.age);
정답 보기
undefined — 존재하지 않는 속성에 접근하면 에러가 아니라 undefined가 반환됩니다.
Q2. 변수 k = "price"일 때, item 객체의 price 값을 가져오는 올바른 코드는?
(가) item.k   (나) item[k]   (다) item."k"
정답 보기
(나) item[k] — 키가 변수에 들어 있을 때는 대괄호 표기법을 사용해야 합니다. item.k는 이름이 "k"인 속성을 찾습니다.
Q3. car 객체에서 color 속성을 완전히 제거하는 코드를 작성하세요.
정답 보기
delete car.color; (또는 delete car["color"];)
참고로 car.color = undefined는 값만 비울 뿐 키는 남아 있습니다.
Q4. 다음 코드의 출력 결과는?
const cat = {
  name: "치즈",
  sound() {
    return this.name + ": 야옹";
  }
};
console.log(cat.sound());
정답 보기
치즈: 야옹 — cat.sound()로 호출했으므로 메서드 안의 this는 cat입니다.
Q5. 아래 객체의 모든 키와 값을 "키 = 값" 형태로 출력하는 for...in 코드를 작성하세요.
const info = { 이름: "홍길동", 나이: 30, 직업: "개발자" };
정답 보기
아래 코드를 실행해 보세요.
/* ===== 실행 순서 =====
 * ① 객체 생성
 * ② for...in으로 키를 꺼내고 info[key]로 값 출력
 * ====================== */
const info = { 이름: "홍길동", 나이: 30, 직업: "개발자" };

for (const key in info) {
  console.log(key + " = " + info[key]);  // 값은 대괄호로!
}

12파일 저장 및 실행 방법
